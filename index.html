!使用前请先完成以下准备（Colab）
  1. 登录网站：https://colab.research.google.com/
  2. 点击 “文件” → “在云硬盘中新建笔记本”，然后设置 “代码执行程序 → 更改运行时类型 → T4 GPU”。
  3. 先运行 !nvidia-smi 确认 GPU 正常，再开始执行本代码。
💡 以上 3 条也会自动写入生成脚本最前面的注释区，方便日后回看。
!使用前请先完成以下准备（Kaggle）
  1. 打开 https://www.kaggle.com/code，点右上角 Create New Notebook。
  2. 右侧 Session options 面板：Accelerator 选 GPU T4 ×2，Internet 开关拨到 On。
  3. 新建格子先运行 !nvidia-smi 确认 GPU 正常，再继续。
💡 双卡并行：同一 Notebook 内启动两个 ComfyUI 进程，分别绑定 GPU 0 和 GPU 1；可按需选择分配策略。
